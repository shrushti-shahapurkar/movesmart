How does the ML model work?

  1. Reads valid gameplay scores from the CSV dataset.
  2. Converts age and game name into numeric features.
  3. Trains a Random Forest regression model.
  4. Evaluates performance on held-out records when enough data is available.
  5. Estimates a score for the selected game and age.

Important: This is an educational gameplay-score prediction demonstration, not a validated screening tool. Predictions may be inaccurate when data is limited or unrepresentative. They must not be used to diagnose or classify a child or predict a health condition.
